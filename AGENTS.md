# AI Agent Guidance for shell-practice

This repository contains simple Bash practice scripts and does not currently include project documentation, build scripts, or test automation.

## What this repository is

- A collection of standalone Bash script examples in the repository root.
- Scripts are named like `01-hello_World.sh`, `02-conversation.sh`, etc.
- The scripts are intended for learning and shell scripting practice, not as a production application.

## How to help

- Keep changes small and focused on the specific script requested.
- Preserve the existing Bash style and shell syntax.
- Do not add complex build infrastructure, dependencies, or new frameworks.
- If a script appears to demonstrate a concept or contain an intentional error, ask before making major changes.

## Validation

- There is no repository-level build/test command.
- Use `bash <script>.sh` to verify individual scripts.
- If available, `shellcheck` is a useful static checker for Bash syntax and style.

## Notes for agents

- Avoid auto-populating new content or creating additional files unless the user explicitly requests it.
- Do not assume anything beyond the scripts that exist in the repository root.
- If asked to refactor or extend examples, prefer minimal edits and keep behavior consistent.
